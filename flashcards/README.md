# 填词补文 · 120 词闪卡

自考英语（专升本）「填词补文」高频词的在线闪卡。配合《填词补文 5 天刷题计划》使用：第 1 天 40 个动词、第 2 天 40 个名词、第 3 天 40 个形容词 / 副词，正好对上计划里的三天词表。

纯静态站点：无框架、无构建、无依赖。双击 `index.html` 就能用，也可以直接部署到 GitHub Pages。文字与进度完全离线保存；单词发音走 Edge TTS，需要联网（断网会自动退回系统语音）。

![预览](preview.png)

## 功能

- **按天分组**：全部 / 第 1 天 / 第 2 天 / 第 3 天，和 5 天计划一致。
- **双向练习**：英 → 中（认词义）、中 → 英（想拼写）；卡片 3D 翻面。
- **快刷评分**：`不认识` 会在 3 张后重来，`模糊` 放回队尾，`认识` 才算过关；键盘 `← ↓ →` 直接评分。
- **真题例句**：每个词尽量配一条来自 26 套真题原文的句子（挖空处已填回答案词），标注考期。
- **错词 / 收藏**：自动记录不认识的词，可只刷错词；星标收藏难词。
- **发音（Edge TTS）**：单词音频由 Edge TTS Worker 实时合成，手机、微信内也能播；6 个英文音色、4 档语速，可开关「显示卡片时自动朗读」。
- **进度保存**：认识 / 模糊 / 不认识、收藏、当前分组都保存在浏览器 `localStorage`（键名 `cloze-flashcards-v1`），不上传服务器。
- **深色模式、手机适配、键盘操作、词表跳转**。

## 目录结构

```
flashcards/
├── index.html            # 页面结构（不含词表）
├── assets/
│   ├── style.css         # 样式
│   ├── app.js            # 交互逻辑（翻面、评分、队列、进度）
│   ├── tts.js            # Edge TTS 发音（解锁、缓存、兜底）
│   └── icon.svg          # favicon
├── data/
│   ├── words.js          # 词表数据（页面实际加载这个文件）
│   └── words.json        # 同一份数据的 JSON 版，方便二次利用
└── README.md
```

**数据与页面分离**：改词只动 `data/words.js`，不用碰 HTML 和 JS。

## 词表字段

```js
{
  "id": "achieve",          // 唯一标识，收藏/进度都用它
  "en": "achieve",
  "cn": "实现；达到",
  "pos": "v.",              // v. / n. / adj. / adv.
  "day": 1,                 // 1 / 2 / 3，对应计划的三天
  "tip": "achieve one's goal 实现目标",   // 固定搭配，可为空
  "ex": "Think about something that ...", // 真题例句，可为空
  "src": "2025年10月"       // 例句出处
}
```

`data/words.js` 的内容是 `window.VOCAB_DATA = { meta, words }`，用普通 `<script>` 加载，所以在 `file://` 下也不会遇到跨域问题。

## 发音（Edge TTS）

单词音频走 Edge TTS Worker 实时合成，不依赖系统语音，因此手机和微信内置浏览器也能正常发音。

- 接口：`POST https://api.xiemojy.mom/v1/audio/speech`，请求体 `{ input, voice, speed }`，返回 `audio/mpeg`。
- 音色：右上角齿轮里可选 6 个英文音色（美音 / 英音 / 澳音），语速 0.8–1.1。
- 缓存：同一「单词 + 音色 + 语速」只请求一次（LRU 160 条 Blob URL），当前卡片还会预取，点喇叭几乎立即出声。
- 微信 / iOS：首次需要一次用户手势解锁音频（点页面任意处或先点一次喇叭）；失败会自动退回浏览器本机语音，并弹出提示。
- 改接口或默认音色：编辑 `assets/tts.js` 顶部的 `ENDPOINT` / `DEFAULT_VOICE` / `DEFAULT_SPEED`。

> 说明：接口是第三方 Worker，需要联网；断网时会退回系统语音（桌面 Chrome、安卓可用）。

## 本地预览

直接双击 `index.html` 即可。

也可以起一个静态服务器（手机同 Wi-Fi 访问时更方便）：

```bash
python -m http.server 8000
# 打开 http://localhost:8000/flashcards/
```

## 部署到 GitHub Pages

**方式一：放在现有站点里（推荐）**

把整个 `flashcards/` 文件夹上传到仓库根目录，访问：

```
https://<用户名>.github.io/<仓库名>/flashcards/
```

本站首页侧栏已经加了「词汇闪卡」入口，指向上面的地址。

**方式二：单独建一个仓库**

新建仓库，把 `flashcards/` **里面的内容**（`index.html`、`assets/`、`data/`）上传到仓库根目录，然后在 Settings → Pages 选择 `main` 分支 `/ (root)`，访问：

```
https://<用户名>.github.io/<仓库名>/
```

> 网页上传时务必把 `assets/` 和 `data/` 两个文件夹一起传上去，否则样式、脚本或词表会 404。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `空格` / `回车` | 翻面 |
| `←` | 不认识（3 张后重来） |
| `↓` | 模糊（放回队尾） |
| `→` | 认识（过关） |
| `S` | 收藏 / 取消收藏 |
| `Esc` | 关闭词表 |

手机上也可以左右滑动卡片：左滑「不认识」，右滑「认识」。

## 数据来源

- 120 个词取自《填词补文 5 天刷题计划》第三节词表（动词 40、名词 40、形容词 25 + 副词 15）。
- 例句从 2013—2026 年 26 套真题的填词补文原文中提取，已把答案词填回原空位；没有合适原句的词只显示释义和搭配。
- 词表与例句的生成脚本在项目构建流程中（不在本目录）；日常扩词直接在 `data/words.js` 按上面的字段追加即可，`words.json` 可选同步。
