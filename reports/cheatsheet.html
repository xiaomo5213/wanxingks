01四步法

  1. 1
    定时态语态

    圈出 have/be/will/ago/now/since，先判断主动还是被动、现在还是过去。

  2. 2
    看前后定词性

    冠词、介词后多为名词；名词前多为形容词；动词、形容词、句首多为副词。

  3. 3
    定具体形式

    时态、语态、单复数、比较级、否定前缀；一个空只改一个核心形式。

  4. 4
    拼写回读

    双写、y→i、去 e、句首大写；把答案放回原句读一遍，语法语义都通才保留。

05词形变化

名词-tion/-sion · -ment · -ness · -ity · -ance/-ence · -er/-or
形容词-ful · -less · -ive · -able/-ible · -al · -ous · -ed/-ing
副词-ly （friendly / lovely / likely 是形容词）
动词-en · en- · -ify · -ize （deepen / enable）
否定un- · in- · im- · ir- · il- · dis-
比较-er / more；-est / most （good / better / best 等不规则）

06最容易错的 8 组

  • interested / interesting：人感到 / 物令人；surprised / surprising 同理。
  • hard / hardly：努力、猛烈 / 几乎不；near / nearly：近的 / 将近。
  • true → truth；wide → width；long → length；strong → strength。
  • explain → explanation；decide → decision；describe → description。
  • succeed → success → successful → successfully，四个词性别混。
  • effect（名词）/ affect（动词）：have an effect on / affect sb。
  • able → ability / enable；important ↔ importance 看空格方向。
  • use → used / using / uses；used to do / be used to doing。

07高频词族

nature / natural / naturally use / used / using effect / effective / effectively real / really able / enable / ability help / helps / helpful important / importance different / difference success / successful possible / impossible correct / incorrect near / nearly probable / probably require / requires mistake / mistakes wise / wisely

09训练建议

  • 每天 1 套：限时 10 分钟，先写后看答案。
  • 错题四栏：原词 / 我写的 / 正确形式 / 错因。
  • 按标签补弱：过去分词、名词化、否定前缀。
